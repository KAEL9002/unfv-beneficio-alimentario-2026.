Requisitos de Software: Tener instalado Power BI Desktop (versión actualizada a 2024 o superior) y Microsoft Excel.

Ejecución: Clonar o descargar el repositorio desde GitHub ([https://github.com/KAEL9002/unfv-beneficio-alimentario-2026](https://github.com/KAEL9002/unfv-beneficio-alimentario-2026)).   

Abrir el archivo pbix/Dashboard_Comedor_UNFV_2026.pbix directamente en Power BI Desktop.

En caso de requerir reconfigurar la ruta del origen de datos, ir a Transformar datos - Configuración de origen de datos y apuntar al archivo Excel alojado en la carpeta data/.
